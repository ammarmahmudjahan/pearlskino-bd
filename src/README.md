# PearlSkino BD — Refined CSS

The original class names are preserved. CSS is separated by page while shared rules live in `common.css`. `styles.css` imports the complete bundle.

### Files
`common.css` · `home.css` · `shop.css` · `product.css` · `cart.css` · `checkout.css` · `about.css` · `contact.css` · `success.css` · `branding.css` · `styles.css`

### Explore button
The competing effects are merged into one: subtle slow idle breathing, stronger hover lift, one glossy sweep, and a tactile icon rotation. Touch devices get press feedback instead of hover behaviour.

### Mobile
Additional tablet/phone breakpoints improve grids, hero typography, forms, cart controls, navigation overflow, and touch target sizing. Reduced-motion support is included.

### React
For the easiest migration, replace the old CSS import with `styles.css`. If you want page-level loading, import `common.css` plus the CSS for the active page.
